# SWS Web Console 🎵

Sound Wave Script - Web-based Music Notation and Synthesis Tool

## 🚀 Quick Start

### Online (GitHub Pages)
Visit: **https://francium87arc-cyber.github.io/SWS** (or your configured URL)

### Local Development
```bash
# Clone the repository
git clone https://github.com/francium87arc-cyber/SWS.git
cd SWS

# Open in browser (Simple HTTP Server)
python -m http.server 8000

# Visit: http://localhost:8000/SWS(2).html
