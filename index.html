Sound Wave Script - Web-based Music Notation & Synthesis

What is SWS?

Sound Wave Script (SWS) is a powerful, browser-based music notation and synthesis tool. Write music in an intuitive scripting language and hear it play in real-time using Web Audio API.

Perfect for:

  • Composing and prototyping music
  • Learning music theory and synthesis
  • Converting between UST (UTAU) and standard formats
  • Creating polyrhythmic compositions with independent tracks

🎼 Track System

Manage multiple independent tracks with different instruments and timing. Perfect for polyphonic compositions.

🎹 Web Audio Playback

Real-time synthesis using the Web Audio API. No plugins required - works in any modern browser.

📝 Intuitive Syntax

Simple, readable scripting syntax for defining notes, timing, tempo, and more. Learn in minutes.

🔄 UST Support

Import UTAU UST files and convert them to SWS format. Export your compositions back to standard formats.

🎵 Chords & Slurs

Create complex musical expressions with chord syntax (fsn=[C4,E4,G4]) and note slurring.

💾 Save & Load

Save your projects as .ss files, load UST files, and export your final compositions.

Quick Example

tempoconst="120";
key="C";

snd("synth",4,C4);
snd("synth",4,E4)-cnt-snd("synth",4,G4);
sleep(4);

snd("piano",4,C4~);
snd("piano",4,C4);

chips riff(){
    snd("piano",8,C4);
    snd("piano",8,E4);
}

chips(riff);

lp(4){
    snd("bass",8,C2);
}
